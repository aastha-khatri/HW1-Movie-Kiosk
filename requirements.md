# Movie Kiosk Requirements

1. **View movies and showtimes:** The customer can see the available movies and the showtimes for each movie.
2. **Choose a seat:** The customer can select an available seat for the chosen showtime.
3. **Purchase a ticket:** The customer can buy a ticket for the selected movie, showtime, and seat.
4. **Receive confirmation:** After a successful purchase, the system provides a confirmation of the ticket purchase.
5. **Prevent duplicate seat sales:** Once a seat is sold for a showtime, the system must not sell that same seat again for that showtime.
